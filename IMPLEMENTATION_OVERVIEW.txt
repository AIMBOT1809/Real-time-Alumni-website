================================================================================
HOW IT WORKS - FLOW DIAGRAM
================================================================================

User clicks Connect button
        ↓
[AlumniGrid] logs: User ID, Target Alumni ID, API request
        ↓
Frontend → POST /api/conversations with x-user-id header
        ↓
[POST /conversations] logs: Received IDs, looking up conversations
        ↓
Backend checks: Existing conversation? New conversation? Add participants?
        ↓
[POST /conversations] logs: Database operation results
        ↓
If success: Backend returns conversation ID
If failure: Backend logs full error details

        ↓
Frontend receives response
        ↓
[AlumniGrid] logs: API response status, error (if any)
        ↓
If success: Navigate to /chat with conversationId in state
If failure: Show error to user

        ↓
Chat page loads with conversationId in state
        ↓
Chat component auto-selects conversation
        ↓
User can send message

COMMON FAILURE SCENARIOS
================================================================================

Scenario 1: RLS Policy Error (PGRST301)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Last log: [POST /conversations] Error inserting participants
          { code: 'PGRST301', message: 'row violates RLS policy' }

Issue: Supabase RLS policy on conversation_participants too restrictive
Fix:   Update policy to allow inserts for any authenticated user

Scenario 2: User ID Undefined
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Last log: [AlumniGrid] Current User ID: undefined

Issue: User not logged in or user object corrupted
Fix:   Log in again, check localStorage for user data

Scenario 3: Alumni ID Undefined
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Last log: [AlumniGrid] Target Alumni user_id: undefined

Issue: Alumni object doesn't have user_id field
Fix:   Check actual field name (could be id, user_id, userId, profile_id)

Scenario 4: API Returns 500 Error
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Backend exception or database issue
Fix:   Check backend logs for detailed error message

Scenario 5: Navigation Fails
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
